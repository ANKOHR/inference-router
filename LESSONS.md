# Lessons for KOML

The domain requires a distinction between routing policy correctness and model suitability. Without model calls or measured capability data, declared requirements can select an illustrative tier reproducibly, but they cannot establish which model will solve the task.

The validated assumption is that an offline deterministic policy can reconcile 200 planted records exactly, and that changing labels or requirements changes computed evidence. The stronger assumption that these thresholds yield accurate real-world choices remains untested. The fixture repeats only five cases and must not be advertised as 200 independent semantic judgments.

Operating rule for future builds: maintain an independently derived oracle and a corruption test, and keep synthetic policy agreement separate from measured real-world utility. Do not convert an acceptance demo into a claim of saved money, saved time or model quality.
